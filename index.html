PROJETOS

POKÉDEX CLÁSSICA

Pokédex Dobrável é uma aplicação interativa inspirada no clássico dispositivo do universo Pokémon. Desenvolvida com HTML, CSS e JavaScript, ela consome dados da PokéAPI para exibir informações dos 151 Pokémon da primeira geração. O design simula uma Pokédex física, com navegação intuitiva, busca por nome e visual responsivo. Esse projeto reforçou meus conhecimentos em consumo de APIs, manipulação de DOM e design criativo.

RAYQUAZA 2.0

Este projeto evoluiu de um trabalho académico na Uninove para uma aplicação profissional de alta performance. Mantendo a funcionalidade original de consulta de CEP e meteorologia em tempo real, a versão 2.0 traz um redesign moderno e foco total em experiência mobile. Implementei uma interface mais limpa e fluida, garantindo que a aplicação seja 100% responsiva, demonstrando a minha capacidade de refatoração e otimização de UI/UX.

Jogo da Velha Inclusivo: Ferramenta para Neurodiversidade

Este projeto foi concebido com a missão de ir além de um simples jogo, transformando o clássico "Jogo da Velha" em uma ferramenta educacional e lúdica, especificamente desenhada para auxiliar crianças com dificuldades neurodivergentes. O desenvolvimento foi guiado por princípios de Acessibilidade e Usabilidade, visando criar uma experiência simples, com distrações mínimas e feedback visual claro para reforçar o aprendizado de regras, concentração e raciocínio lógico-espacial.

Bora Tomar Uma

"Bora Tomar Uma" é uma aplicação web interativa que utiliza a API do Open Brewery para fornecer aos usuários uma experiência divertida e informativa sobre cervejarias. Com um design moderno e responsivo, o projeto permite que os usuários explorem diferentes tipos de cervejas, descubram novas marcas e aprendam sobre o processo de fabricação. Desenvolvido com HTML, CSS e JavaScript, este projeto destaca minhas habilidades em consumo de APIs, design de interfaces e desenvolvimento front-end.
